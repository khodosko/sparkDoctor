# Development Standards

## Unit Testing

- Every new feature, behavior, parser rule, analyzer rule, recommendation rule, and output format change must include unit tests.
- Creating new unit tests is allowed when adding or changing functionality.
- Existing unit tests must not be edited to fix a failing test without explicit approval from the project owner.
- If an existing unit test fails, treat the failure as a product or implementation signal first.
- Before modifying an existing failing test, document the failure and get approval from the project owner.
- Do not weaken, delete, skip, or loosen existing assertions without approval.
